# 开发规划

本页区分已发布功能与仍需在目标环境核对的事项。开发完成不代表所有板子固件和网络条件均已验收；新增开发范围在实现前确认。

## 已完成

- [x] **云端录音支持**（正式版 v1.1.1）：经受控代理的 HTTPS 上传、路径令牌校验、来源限制、限流与容量保护，复用录音保存、关联、播放、下载与通知；包含录音缺失与迟到的独立提醒。部署见[公网录音接收](voicemail.md#公网录音接收)。
- [x] **备份包含录音文件**（v1.1.2）：数据库备份可勾选同时包含已关联、未关联及目录内完整 AMR；校验索引、大小和摘要，缺失或损坏时明确失败。恢复到全新目录并保留外发保护，兼容旧格式 1 数据库 ZIP；格式 2 需要新版工具，见[数据维护](data-maintenance.md)。

## 部署核对

- HTTPS 上传的证书兼容性、网络可达性及上传稳定性按目标固件核对；能播放接通提示语，不等于录音已成功上传。
- 在目标浏览器核对播放与下载；录音缺失、迟到、关联及通知的边界见[留言说明](voicemail.md)。
- 备份和恢复已有离线合成测试；实际迁移仍需核对空间、权限、数据范围及恢复保护，见[数据维护](data-maintenance.md)。

此前记录的两项开发均已完成，当前没有另列已确认的待开发功能。部署核对不表示功能尚未实现，也不要求在生产环境重复破坏性测试。
