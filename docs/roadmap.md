# 开发规划

本页记录开发与待验收的功能，不代表当前版本已支持，也不承诺发布时间。具体方案和开发范围在实现前确认。

## 留言

- [x] **云端录音支持**：v1.1.1-rc.4 已实现经受控代理的 HTTPS 上传、路径令牌校验、来源限制、限流与容量保护，复用录音保存、关联、播放、下载与通知。已取得真实板子经 Tunnel 上传、关联与 Bark 留言提醒的现场反馈；这不代表所有固件及网络条件均已验收。具体固件的 TLS 兼容性、上传稳定性、播放及 rc.5 新增缺失/迟到提醒仍需在目标部署核对。部署见[公网录音接收](voicemail.md#公网录音接收)。
- [ ] **备份包含录音文件**（未排期）：支持将数据库与 AMR 录音一并备份和恢复，包含已关联和尚未关联的录音；核对索引与文件的一致性、完整性，并明确缺失文件的处理方式。保留对既有数据库 ZIP 的恢复兼容。目前 ZIP 不含录音，仍需单独保存和恢复 `voicemail/`，见[数据维护](data-maintenance.md)。
