# 开发规划

本页记录待开发的功能，不代表当前版本已支持，也不承诺发布时间。具体方案和开发范围在实现前确认。

## 留言

- [ ] **云端录音支持**（未排期）：支持板子向云端部署的 SIMHarbor 上传录音，并完成保存、来电关联、播放、下载和留言通知。需明确上传入口、来源校验和访问保护，并补充云端部署说明及现场验证。目前录音上传仍仅支持本地部署，见[留言说明](voicemail.md)。
- [ ] **备份包含录音文件**（未排期）：支持将数据库与 AMR 录音一并备份和恢复，包含已关联和尚未关联的录音；核对索引与文件的一致性、完整性，并明确缺失文件的处理方式。保留对既有数据库 ZIP 的恢复兼容。目前 ZIP 不含录音，仍需单独保存和恢复 `voicemail/`，见[数据维护](data-maintenance.md)。
