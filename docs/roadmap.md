# 开发规划

本页记录开发与待验收的功能，不代表当前版本已支持，也不承诺发布时间。具体方案和开发范围在实现前确认。

## 留言

- [x] **云端录音支持**：v1.1.1-rc.4 已实现经受控代理的 HTTPS 上传、路径令牌校验、来源限制、限流与容量保护，复用录音保存、关联、播放、下载与通知。已取得真实板子经 Tunnel 上传、关联与 Bark 留言提醒的现场反馈；这不代表所有固件及网络条件均已验收。具体固件的 TLS 兼容性、上传稳定性、播放及本版新增缺失/迟到提醒仍需在目标部署核对。部署见[公网录音接收](voicemail.md#公网录音接收)。
- [x] **备份包含录音文件**（v1.1.2-rc.1）：数据库备份可勾选同时包含已关联、未关联及目录内完整 AMR；校验索引、大小和摘要，缺失或损坏时明确失败。恢复到全新目录并保留外发保护，兼容旧格式 1 数据库 ZIP；格式 2 需要新版工具，见[数据维护](data-maintenance.md)。

上述两项开发已完成；目标固件、现场网络稳定性和部署验收仍按实际环境确认，不因勾选完成而视为真机全链路验收。
