# 开发规划

本页列出主要功能的实现状态与后续规划；详细版本变更见[更新记录](../CHANGELOG.md)。

## 已实现

- [x] **云端录音支持**（v1.1.1）：经受控代理的 HTTPS 上传、路径令牌校验、来源限制、限流与容量保护，复用录音保存、关联、播放、下载与通知；包含录音缺失与迟到的独立提醒。部署见[公网录音接收](voicemail.md#公网录音接收)。
- [x] **备份包含录音文件**（v1.1.2）：数据库备份可勾选同时包含已关联、未关联及目录内完整 AMR；校验索引、大小和摘要，缺失或损坏时明确失败。恢复到全新目录并保留外发保护，兼容旧格式 1 数据库 ZIP；格式 2 需要新版工具，见[数据维护](data-maintenance.md)。

## 后续规划

暂无待开发条目。

## 兼容性与部署要求

- 录音上传依赖目标固件的 HTTPS 兼容性及网络可达性，需同时配置代理来源和上传令牌，见[公网录音接收](voicemail.md#公网录音接收)。
- 浏览器播放和录音关联要求见[留言说明](voicemail.md)。
- 迁移前检查空间、权限、备份完整性及恢复保护，见[数据维护](data-maintenance.md)。
